### Nat vs Internet Gateway

NAT Gateway — это управляемый AWS-сервис, который позволяет ресурсам с приватными IP-адресами инициировать исходящие соединения с Internet, выполняя трансляцию их приватных IP-адресов в публичный IP-адрес NAT Gateway и обеспечивая возврат ответного трафика.

|                                              | **Internet Gateway (IGW)**              | **NAT GateWay**                         |
| -------------------------------------------- | --------------------------------------- | --------------------------------------- |
| Для чего                                     | Связывает VPC с Internet                | Даёт private resources выход в Internet |
| Где используется                             | Public subnet                           | Private subnet                          |
| Нужен public IP ресурсу                      | **Да**                                  | **Нет**                                 |
| Может принимать новые соединения из Internet | **Да**, если SG/NACL/маршруты позволяют | **Нет**                                 |
| Исходящий трафик                             | Да                                      | Да                                      |
| Подменяет private IP                         | Нет                                     | **Да, NAT**                             |
| Managed AWS service                          | Да                                      | Да                                      |
| Платный                                      | Нет отдельной почасовой платы           | **Да**                                  |


> [!NOTE]
> NAT Gateway позволяет private-ресурсу инициировать соединение с внешним ресурсом и получить ответ обратно, не делая private-ресурс доступным для новых входящих соединений из Internet.
>
> NAT Gateway обеспечивает обратную доставку ответа на исходящее соединение, выполняя трансляцию адресов.
