### Security Group

Это виртуальный stateful firewall, применяемый к сетевым интерфейсам (ENI) AWS-ресурсов.

Security Group работает по принципу deny by default: новый трафик разрешён только при наличии соответствующего ALLOW-правила. Явных DENY-правил в Security Group нет.

Есть важное свойство stateful.

Если клиент инициировал разрешённое соединение с удалённым ресурсом:
```
Client ───────→ 1.1.1.77:4444
```

и исходящий трафик разрешён, то ответный трафик в рамках этого соединения автоматически разрешается, даже если отдельного правила, разрешающего входящий трафик от 1.1.1.77:4444, нет:
```
Client ←─────── 1.1.1.77:4444
       response
       ✓ ALLOWED
```

Но если 1.1.1.77:4444 самостоятельно инициирует новое соединение:
```
1.1.1.77:4444 ───────→ Client NEW connection
```
оно будет проверено по INGRESS-правилам Security Group и будет заблокировано, если соответствующего ALLOW-правила нет.
