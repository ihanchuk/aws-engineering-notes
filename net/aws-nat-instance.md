# NAT Instance

NAT instance — это обычный EC2-инстанс, настроенный выполнять роль NAT для приватных subnet'ов. И если возникает вопрос зачем он нужен когда уже есть NAT Gateway, то 
ответ очень простой - все дело в экономии денег. Сам по себе NAT Gateway стоит слишком дорого. 

#### Давайте рассмотрим стоимость `NAT instance` vs `NAT Gateway`



| Расчет | NAT Instance (t3.micro) | NAT Gateway |
| -------------------|---------------------------------------|---------------------------------------|
| Стоимость в час | 0.0104 USD | 0.045 USD |
| За день (аренда) | 0.0104 USD * 24(h) = **0.25 USD** | 0.045 USD * 24(h) = **1.08 USD** |
| За месяц (аренда) | 0.0104 USD * 24(h) * 30(d) = **7.49 USD** | 0.045 USD * 24(h) * 30(d) = **32.40 USD** |
| За год (аренда) | 0.0104 USD * 24(h) * 365(d) = **91.10 USD**| 0.045 USD * 24(h) * 365(d) = **394.20 USD**|
| Плата за обработку трафика (Data Processing) | **0.00 USD** (нет наценки за гигабайт) | **0.045 USD** за каждый 1 GB |
| Плата за выход в интернет (AWS Egress) | ~0.09 USD за 1 GB (после 100 GB free) | ~0.09 USD за 1 GB (после 100 GB free) |
