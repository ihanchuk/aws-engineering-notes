### VPC Latice


__AWS VPC Lattice__ — это сервис для связи и управления коммуникацией между сервисами в разных VPC, аккаунтах и даже через AWS/гибридные границы.

> [!TIP]
> VPC Lattice = application networking для сервисов, а не просто networking между VPC

Он позволяет централизованно настроить:

- service-to-service communication;
- service discovery;
- маршрутизацию;
- authentication/authorization через IAM;
- доступ между VPC и AWS accounts;
- observability;
- HTTP/HTTPS и gRPC traffic.
