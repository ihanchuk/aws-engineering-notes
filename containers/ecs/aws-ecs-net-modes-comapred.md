# AWS Ecs Net Modes Summary

| **Характеристика**                  | **Host Mode**                          | **Bridge Mode**                           | **AWSVPC Mode**                              |
|-------------------------------------|----------------------------------------|-------------------------------------------|----------------------------------------------|
| **Кому принадлежит IP?**            | Инстансу EC2                           | Внутренней сети Docker (NAT)              | **Самой задаче (Task)** из подсети VPC       |
| **Поддержка AWS Fargate**           | Нет                                    | Нет                                       | **Да (режим по умолчанию)**                  |
| **Поддержка EC2**                   | Да                                     | Да                                        | Да                                            |
| **Управление портами**              | Статическое (один порт на хост)       | **Динамическое** (ephemeral-порты)        | Прямое (у каждой задачи свои порты)          |
| **Запуск копий на одном хосте**     | Невозможен (конфликт портов)           | Да (через разные порты хоста)             | **Да** (у каждой копии свой IP)              |
| **Настройка Security Groups**       | Только на уровне всего EC2             | Только на уровне всего EC2                | **На уровне конкретной задачи (Task)**       |
| **Производительность сети**         | **Максимальная** (напрямую)            | Средняя (задержки из-за Docker NAT)       | Высокая (инфраструктура AWS Nitro)           |
| **Главный плюс**                    | Наименьшая задержка (Latency)          | Экономия IP, гибкость для EC2             | **Максимальная безопасность и изоляция**     |
| **Главный минус**                   | Ограничения масштабирования            | Сложнее мониторить сетевой трафик         | Ограничения по количеству ENI на инстанс     |
