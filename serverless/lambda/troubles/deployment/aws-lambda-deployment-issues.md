# Проблемы с установкой пакетов в AWS Lambda

Код вашей Lambda-функции состоит из скриптов или скомпилированных программ, а также их зависимостей. Для загрузки этого кода в AWS используется установочный пакет (deployment package). 

Когда вы обновляете функцию, Lambda применяет изменения, запуская новые инстанции с обновленным кодом или настройками. Ошибки деплоя (развертывания) не позволяют использовать новую версию и могут возникать из-за проблем с установочным пакетом, самим кодом, правами доступа или инструментами сборки.

---

## Симптомы проблем с установочным пакетом

При вызове функции вы получаете одну из следующих ошибок:

### 1. Ошибка импорта модуля (Unable to import module)
* **Пример:** `Unable to import module 'index': No module named index` или `Runtime.ImportModuleError`.
* **Что значит:** Среда выполнения Lambda не может найти главный файл (обработчик/handler) вашего приложения или какую-то из его зависимостей (библиотек).

### 2. Ошибка нарушения прав доступа (Permission denied)
* **Пример:** `module initialization error: [Errno 13] Permission denied: '/var/task/lambda_function.py'`.
* **Что значит:** Файл физически присутствует в системе, но операционная система внутри контейнера AWS Lambda не имеет прав на его чтение или запуск.

---

## Причины возникновения проблем

Ниже приведены три самые распространенные причины таких ошибок:

### 1. Неправильная структура папок в архиве
При создании `.zip` архива вручную или через скрипты автоматизации код был запакован некорректно. Например, если вы заархивировали саму папку с проектом, а не её содержимое, то файлы внутри архива окажутся по пути `my-folder/index.js` вместо корневого `index.js`. Lambda ожидает увидеть главный файл строго в корне архива.

### 2. Неверные UNIX-права доступа к файлам
Контейнеры AWS Lambda работают под управлением операционной системы Amazon Linux. Если вы упаковывали проект на Windows или с некорректными правами на macOS/Linux, файлы могут потерять нужные атрибуты. 
* **Правильный стандарт:** Все файлы в архиве должны иметь права **644** (чтение для всех), а все папки — **755** (чтение и выполнение для всех).

### 3. Несовместимая архитектура бинарных файлов (Binaries)
Пакет содержит одну или несколько скомпилированных библиотек (например, модули Node.js с бинарными вставками или Python-пакеты вроде `pandas` / `numpy`), которые были собраны под архитектуру вашего локального компьютера (например, Windows x64 или macOS M1/M2/M3 Apple Silicon), но несовместимы с процессорами и ОС внутри Lambda (Amazon Linux, архитектуры x86_64 или ARM64).
