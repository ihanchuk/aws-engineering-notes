# AWS SQS Modes

# 2 режима работы Amazon SQS

В сервисе **Amazon SQS (Simple Queue Service)** доступно **два типа очередей**, которые определяют режим работы с сообщениями:

## 1. Стандартные очереди (Standard Queues)

* **Порядок сообщений:** Не гарантируется жесткий порядок (принцип *best-effort ordering*). Сообщения могут приходить не в том порядке, в котором были отправлены.
* **Количество доставок:** Гарантируется доставка **минимум один раз** (*at-least-once delivery*). В редких случаях копия сообщения может быть доставлена повторно.
* **Пропускная способность:** Практически **безлимитная**. Поддерживает почти неограниченное количество транзакций (TPS) на чтение и запись.

## 2. Очереди FIFO (First-In-First-Out)

* **Порядок сообщений:** Строго соблюдается принцип **«первым пришел — первым ушел»**. Сообщения обрабатываются в точном порядке их поступления.
* **Количество доставок:** Гарантируется обработка **строго один раз** (*exactly-once processing*). Дубликаты автоматически удаляются в течение 5-минутного окна.
* **Пропускная способность:** Ограничена (по умолчанию до 300 транзакций в секунду или до 3000 при использовании пакетной обработки).

---

### Сравнительная таблица

| Характеристика | Стандартная очередь | Очередь FIFO |
| :--- | :--- | :--- |
| **Порядок доставки** | Best-effort (возможны перестановки) | Строго FIFO (точный порядок) |
| **Дублирование** | Допускается (At-least-once) | Исключено (Exactly-once) |
| **Пропускная способность** | Почти безлимитная | Ограниченная (с возможностью расширения) |
| **Использование** | Когда важна скорость, а порядок не критичен | Когда важна последовательность транзакций |
