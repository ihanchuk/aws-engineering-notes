# AWS SQS

Amazon SQS (Simple Queue Service) — это полностью управляемая служба очередей сообщений, которая позволяет разделять (декуплировать) и масштабировать микросервисы, распределенные системы и бессерверные приложения.

Главная задача SQS — временно сохранить сообщение в надежном хранилище, пока принимающий сервис (потребитель) не будет готов его забрать и обработать.


### Лимиты

- __Максимальный размер сообщения__: 256 КБ.  <br> Если нужно передать больше, используют паттерн, когда сам файл загружают в Amazon S3, а в SQS отправляют только ссылку на этот файл.
- __Время жизни сообщения__ (TTL): Сообщение может храниться в очереди от 1 минуты до максимум 14 дней (по умолчанию 4 дня). Если за 14 дней его никто не прочитал, оно удаляется.
