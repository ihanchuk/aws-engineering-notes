| Resource                        | Что представляет                             |
| ------------------------------- | -------------------------------------------- |

| `AWS::Serverless::Connector`    | Связь / permissions между ресурсами          |
| `AWS::Serverless::GraphQLApi`   | AWS AppSync GraphQL API                      |
