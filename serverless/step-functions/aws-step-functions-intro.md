# AWS Step Functions #  
Это полностью управляемый serverless-сервис для оркестрации рабочих процессов. Он позволяет объединять различные сервисы AWS в единый **workflow**, 
управляя последовательностью выполнения, переходами между шагами и обработкой ошибок. При этом сама бизнес-логика workflow отделяется от кода отдельных приложений.

Каждый workflow в Step Functions представляет собой **конечный автомат (State Machine)**, который описывается с помощью **Amazon States Language (ASL)** 
в формате JSON или YAML. Для визуального создания и редактирования workflows также используется **Workflow Studio**.

### Amazon States Language (ASL)###

__Amazon States Language (ASL)__ — это JSON-based язык, с помощью которого описывается логика **State Machine** в AWS Step Functions.

В ASL задаются:

* какие шаги выполняются;
* в каком порядке они запускаются;
* какие шаги могут выполняться параллельно;
* куда переходить после выполнения шага;
* что делать при ошибке;
* какие условия проверять;
* какие данные передавать между состояниями.

Простейшая State Machine может выглядеть так:

```json
{
  "StartAt": "ProcessOrder",
  "States": {
    "ProcessOrder": {
      "Type": "Task",
      "Resource": "arn:aws:lambda:eu-central-1:123456789012:function:ProcessOrder",
      "End": true
    }
  }
}
```

Здесь:

* `StartAt` определяет первое состояние;
* `States` содержит все состояния workflow;
* `ProcessOrder` — имя состояния;
* `Type: Task` означает выполнение некоторой операции;
* `Resource` указывает, какой AWS-ресурс должен быть вызван;
* `End: true` завершает workflow после выполнения этого состояния.

ASL описывает **не сам код Lambda**, а именно **управление потоком выполнения**: последовательность, условия, параллельные ветки, обработку ошибок и переходы между состояниями.
